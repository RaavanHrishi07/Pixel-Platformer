# 🎮 Pixel Quest — 2D Platformer

Pixel Quest is a colourful side-scrolling platformer built with Python and Tkinter. Explore different worlds, jump across platforms, collect coins, avoid hazards, and defeat enemies on your way to the finish flag!

## ✨ Features

- **3 unique levels:** Green Hills, Sky Ruins, and Lava Citadel.
- **Platforming mechanics:** Run, jump, and land on platforms.
- **Collectible coins:** Collect coins and track your total score.
- **Moving enemies:** Dodge enemies or jump on them to defeat them.
- **Hazards and lives:** Avoid spikes and falling to stay alive.
- **Side-scrolling camera:** Explore larger worlds as you move.
- **Pause and restart:** Pause the game or restart your current level.
- **Custom pixel-style graphics:** Colourful characters, scenery, and a game HUD.

## 🛠️ Built With

- Python 3
- Tkinter
- Python standard library

## 🚀 Getting Started

### Prerequisites

Install Python 3.11 or a compatible Python 3 version. Tkinter is included with many standard Windows Python installations.

### Installation

Clone the repository:

```bash
git clone https://github.com/RaavanHrishi07/Pixel-Platformer.git
cd Pixel-Platformer
```

### Run the Game

```bash
python main.py
```

### Run Tests

Install pytest if necessary:

```bash
python -m pip install pytest
```

Run the test suite:

```bash
python -m pytest -v
```

## 🎮 Controls

| Key | Action |
|---|---|
| `A` / `D` or `←` / `→` | Move |
| `Space`, `W` or `↑` | Jump |
| `P` | Pause / resume |
| `R` | Restart the current level |
| `Esc` | Quit |
